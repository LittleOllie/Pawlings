# Admin Guide

## Dashboard

Overview of application counts, recent submissions, activity chart, and site status.

## Applications

- **Search** by wallet, reference code, or X handle
- **Filter** by status, date, tag
- **Bulk actions** — Select multiple applications and update status
- **Export** — CSV export of filtered or selected applications

## Application Review

Open any application to:
- View full details and signature
- Change status (Reviewing, Approve, Waitlist, Reject, Archive)
- Add internal notes
- Assign tags
- Approve with option to add wallet to approved list
- See duplicate X handle warnings

## Approved Wallets

- Add wallets manually or via CSV import
- CSV format: `wallet_address,allocation_type,allocation_amount,notes`
- Import shows preview with valid/duplicate/invalid counts
- Export all approved wallets

## Settings

Configure:
- Application availability (open/close, dates, limits)
- Form fields (X, Discord, email, signature, referral)
- Whitelist checker messages
- Project identity and social links
- Editable content (hero, about, FAQ)

## Team (Owner Only)

- Invite new admins via email
- Change roles
- Deactivate admin access
- Cannot remove/demote last owner

## Roles

| Role | Permissions |
|------|------------|
| Owner | Full access including team management |
| Admin | Settings, approved wallets, all review |
| Reviewer | View and review applications, export |
| Read Only | View only |
